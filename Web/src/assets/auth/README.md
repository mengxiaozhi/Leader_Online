# Login brand assets

These official assets are stored locally and imported by the login page so Vite
includes fingerprinted files in the production build. Keep their original colors
and aspect ratios.

- `google-g.png`: Google's official G logo, downloaded unchanged from
  <https://developers.google.com/static/identity/images/g-logo.png>.
  Guidelines: <https://developers.google.com/identity/branding-guidelines>.
- `line-login.png`: LINE's official login icon, extracted unchanged from
  `Line_Login_Button_Image/images/DeskTop/2x/44dp/btn_base.png` in
  <https://vos.line-scdn.net/line-developers/docs/media/line-login/login-button/LINE_Login_Button_Image.zip>.
  Guidelines: <https://developers.line.biz/en/docs/line-login/login-button/>.
